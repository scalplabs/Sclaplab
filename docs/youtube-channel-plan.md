## 1. 한 줄 콘셉트

**"진짜 돈 없이, 진짜처럼 단타 치는 개미들의 마을"**

1,000만 원 가상 계좌로 롱·숏·레버리지 단타를 치고, 번 돈(코인)으로 차를 사서 마을과 서킷을 달리는 모습까지 보여 주는 **모의 트레이딩 + 게임 예능 채널**입니다.

### 왜 이 채널이 될 수 있나
| 앱의 특징 | 영상에서 살리는 법 |
|---|---|
| 가격이 (종목, 날짜) 시드로 정해져 **누가 언제 들어와도 같은 차트** | 시청자가 영상을 보며 **같은 시각에 같은 차트로 따라 하기** 가능 → 참여형 콘텐츠 |
| 실제 한국 시간(KST), 1분봉 = 진짜 1분, 24시간 열림 | 새벽·주말에도 라이브 가능, "지금 들어오세요" 콜투액션이 실제로 통함 |
| 지지·저항, 피보나치, 가짜 돌파, 박스권이 **확률적으로** 나옴 | 차트 공부 교재로 쓰기 좋음 (진짜처럼 잘 통하지만 가끔 뚫림) |
| 롱·숏·레버리지·반대매매·익절/손절(OCO) | 위험한 매매를 **돈 잃지 않고** 체험 → "레버리지 100배 해 봤습니다" 류 자극적이지만 안전한 소재 |
| 공시 뉴스 피드 (유상증자, 자사주 소각, 리콜 보도…) | "뉴스 보고 들어가면 이길까?" 실험 콘텐츠 |
| 개미 마을 · 서킷 · 차 상점(가난→재벌→개갑부) · 대리운전/배달/막노동/불법 알바(검거!) | 트레이딩을 모르는 사람도 보는 **게임 예능** 축 |
| 랭킹 · 명예의 전당 · 닉네임 · 대표 차 | 시청자 대회, 구독자 랭킹전, 명예의 전당 헌액식 |

## 2. 타깃 시청자

1. **주식·코인 입문 2030** – 단타가 궁금하지만 실제 돈을 넣기 무서운 사람
2. **차트 공부 중인 개미** – 지지·저항, 손절 연습장이 필요한 사람
3. **게임/예능 시청자** – 트레이딩은 몰라도 "번 돈으로 슈퍼카 사서 서킷 1등" 서사를 즐기는 사람

**톤:** 친근한 존댓말, 자조적인 개미 유머("익명 개미" 감성), 숫자는 정확하게.

## 6. 첫 영상 대본 – [A-1] 가상 1,000만 원으로 단타 시작합니다

**목표:** 앱이 뭔지 1분 안에 이해시키고, "나도 해 볼까" 클릭을 만든다. 길이 10~12분.

| 구간 | 시간 | 화면 | 대사/내용 |
|---|---|---|---|
| 훅 | 0:00–0:20 | 반대매매 직전 차트 + 잔고 숫자 클로즈업 (엔딩 장면 선공개) | "1,000만 원이… 20분 만에 이렇게 됐습니다. 다행히 진짜 돈은 아니에요." |
| 소개 | 0:20–1:30 | 메인 화면 (차트 · 호가 · 주문창 · 계좌) | "스캘프 랩은 24시간 열려 있는 실시간 모의 시장이에요. 시계는 실제 한국 시간이고, 1분봉은 진짜 1분이에요. 그리고 누가 언제 들어와도 같은 시각엔 같은 가격이라, 이 영상 보시면서 같이 하실 수도 있어요." |
| 규칙 | 1:30–2:30 | 계좌 초기화 → 1,000만 원 | 시리즈 목표 공개: "번 돈 1,000원당 1코인, 이걸로 차를 사서 개갑부 차까지 가는 게 목표입니다." |
| 1차 매매 | 2:30–5:00 | 지지선 그리기 → 지정가 매수 → 익절/손절 걸기 | 지지·저항 도구, OCO 익절·손절을 자연스럽게 소개. 성공 시 리액션 |
| 욕심 | 5:00–8:00 | 레버리지 롱, 뉴스 피드 공시 등장 | 긴장감 구간. 반대매매 라인을 화면에 강조 |
| 결과 | 8:00–9:30 | 체결 내역 · 승률 · 오늘 손익 | 숫자 정리 (체결 횟수, 승률, 오늘 손익) |
| 마을 | 9:30–10:30 | 개미 마을 → 모터스 전시장 | "남은 코인으로 살 수 있는 차는…" 다음 화 떡밥 |
| 엔딩 | 10:30–11:00 | 닉네임 정하기 화면 | "닉네임 정하시면 랭킹에 같이 나와요. 다음 화에서 랭킹 확인해 볼게요." 구독·사이트 링크 안내 |

**제목 후보**
1. 가상 1,000만 원으로 단타 쳐 봤습니다 (진짜 돈 아님)
2. 24시간 안 닫는 모의 주식 시장에서 20분 만에 생긴 일
3. 레버리지 쓰다가 반대매매 당했습니다… 근데 가상이라 괜찮아요

**썸네일:** 왼쪽 큰 빨간/파란 손익 숫자(`-87%` 등) + 오른쪽 놀란 표정 또는 픽셀 차 + 우상단 작게 "모의투자" 배지. 글자는 3~5단어.

## 8. 제작 워크플로

1. **녹화**
   - PC: OBS로 1920×1080 녹화. 차트 영역만 따로 크롭해 둔 장면도 만들어 쇼츠용 세로 편집 시간 절약
   - 모바일: 앱이 폰 레이아웃(차트 전체 폭 → 호가+주문 → 계좌)을 지원하므로 폰 화면 녹화를 그대로 쇼츠로 사용
2. **기록:** 매매할 때 시각(KST)·종목·진입가를 메모 → 설명란에 "같은 차트 보는 법"으로 공개 (시드 덕분에 재현 가능)
3. **편집:** 컷 편집 → 숫자 자막(JetBrains Mono 계열 고정폭 폰트로 앱과 톤 통일) → 효과음(체결음, 반대매매 경고음)
4. **업로드:** 설명란 템플릿 + 면책 문구 + 타임스탬프 + 고정 댓글("닉네임 남겨 주시면 다음 화에서 랭킹 확인합니다")
5. **재활용:** 롱폼 1개 → 쇼츠 2~3개 추출

## 10. 주의할 점

- **투자 권유 오해 금지:** "이 종목 사세요", "이 방법이면 무조건 법니다" 같은 표현은 쓰지 않습니다. 항상 "가상 시장에서는"을 붙입니다.

- **관리자 계정:** 관리자 계정으로 촬영한다면 "내 기록은 랭킹에 안 올리기" 설정을 켜서 시청자 랭킹을 공정하게 유지합니다.
- **개인정보:** 라이브·랭킹 화면에 다른 사용자의 유저 ID(UUID)가 보이지 않게 크롭합니다.

2. 촬영용 계정 만들고 닉네임 설정 (관리자 계정이면 랭킹 제외 옵션 켜기)
3. [A-1] 녹화 (실제 매매 30~40분 녹화 → 11분으로 편집)
4. 녹화본에서 쇼츠 3개 추출
5. 채널 예고편 + 첫 롱폼 업로드, 쇼츠는 월·수·금 예약
