# 카드뉴스 주제 은행: AI 일상 활용 (바로 따라 하는 형)

원칙: 읽는 사람이 카드를 보고 **그 자리에서 복붙해서 따라 할 수 있어야** 저장·공유가 일어난다.
각 주제 = 표지(숫자 + 타겟 + 반박 부제목) + 복붙 프롬프트 + 따라 하는 순서 + 주의 1개.
프롬프트 카드는 꼭 한 장 따로 만든다 (저장 이유가 된다).

---

## 1. 전세·월세 계약서 독소조항 찾기

- 표지: "전월세 계약 앞둔 사람에게 / 계약서에서 꼭 볼 조항 5개" — 부제: 부동산 사장님 말만 믿고 도장 찍을 건가요?
- 순서
  1. 계약서(가계약서·특약사항 포함) 사진을 찍는다. 이름·주민번호는 가린다.
  2. 챗GPT/클로드에 사진을 올리고 아래 프롬프트.
  3. 나온 질문 리스트를 들고 공인중개사에게 물어본다.
- 복붙 프롬프트
  ```
  나는 이 집에 세입자로 들어가려고 해. 첨부한 계약서와 특약사항을 읽고
  1) 세입자에게 불리한 조항
  2) 보증금을 못 돌려받을 위험이 있는 부분
  3) 빠져 있어서 추가해야 할 특약
  을 각각 표로 정리해줘. 각 항목마다 중개사에게 물어볼 질문을 한 줄씩 붙여줘.
  ```
- 같이 넣을 체크 카드: 등기부등본 '을구'의 근저당 금액 + 내 보증금이 집값의 70%를 넘으면 위험 신호, 전입신고·확정일자는 잔금일 당일.
- 주의: AI는 법률 자문이 아니다. 최종 확인은 중개사·법률구조공단(국번 없이 132).

## 2. 싸운 뒤 보낼 카톡, 보내기 전에 AI한테

- 표지: "연애하는 사람에게 / 싸운 뒤 카톡 보내기 전 1분" — 부제: 내가 맞다고 생각하죠? 그 카톡이 이별 사유입니다
- 순서
  1. 보내려던 카톡을 그대로 복사한다.
  2. 아래 프롬프트에 붙여넣는다.
  3. 3가지 버전 중 골라서 내 말투로 고친다.
- 복붙 프롬프트
  ```
  애인이랑 다퉜어. 상황: (한 줄로)
  내가 보내려던 메시지: "(붙여넣기)"
  이 메시지를 상대가 읽으면 어떤 기분일지 먼저 말해주고,
  내 입장은 지키면서 싸움이 커지지 않는 버전 3개로 고쳐줘.
  1) 사과 먼저 2) 내 감정 설명 3) 대화 제안. 각각 3문장 이내, 반말로.
  ```
- 주의: 상대 실명·사진은 넣지 않는다.

## 3. 부모님 보이스피싱·스미싱 판별

- 표지: "부모님 폰 있는 자녀에게 / 사기 문자 판별법 3단계" — 부제: 우리 엄마는 안 속는다고요? 이제 자녀 목소리로 옵니다
- 순서
  1. 이상한 문자를 받으면 링크는 누르지 말고 화면을 캡처한다.
  2. 캡처를 AI에 올리고 아래 프롬프트.
  3. 의심되면 은행·기관 대표번호로 직접 전화(문자 속 번호 금지).
- 복붙 프롬프트
  ```
  이 문자(캡처 첨부)가 사기인지 판단해줘.
  사기라면 어떤 수법인지, 어디가 이상한지 3가지를 쉬운 말로 알려주고,
  내가 지금 해야 할 행동을 순서대로 알려줘. 60대 부모님이 이해할 수 있게.
  ```
- 같이 넣을 카드: 가족끼리 '안전 질문' 정하기(예: 첫 강아지 이름). 목소리가 자녀 같아도 이 질문에 못 답하면 끊는다.
- 신고: 경찰 112, 금융감독원 1332.

## 4. 냉장고 사진 1장으로 일주일 식단

- 표지: "자취생에게 / 냉장고 사진 1장으로 7일 식단" — 부제: 배달비 한 달에 30만 원, 그거 습관입니다
- 순서
  1. 냉장고 문을 열고 사진 1~2장.
  2. 아래 프롬프트.
  3. 장보기 목록만 캡처해서 마트에 간다.
- 복붙 프롬프트
  ```
  첨부한 냉장고 사진에 있는 재료를 먼저 목록으로 적어줘.
  그 재료를 최대한 써서 1인분 기준 7일 저녁 메뉴를 짜줘. 조리시간은 20분 이내.
  부족한 재료는 마지막에 '장보기 목록'으로 묶어주고 예상 금액도 적어줘.
  ```
- 주의: 유통기한은 AI가 모른다. 표시 날짜는 직접 확인.

## 5. 카드 명세서로 새는 돈 찾기

- 표지: "월급 순삭되는 직장인에게 / 카드 명세서 1장으로 새는 돈 3개" — 부제: 가계부 쓰는 사람만 돈 모으는 거 아닙니다
- 순서
  1. 카드 앱에서 지난달 이용내역을 캡처하거나 엑셀로 내려받는다.
  2. 카드번호·이름은 가리고 올린다.
  3. 아래 프롬프트 → 나온 '해지할 구독' 목록부터 정리.
- 복붙 프롬프트
  ```
  첨부한 지난달 카드 이용내역을 분석해줘.
  1) 카테고리별 지출 합계 표
  2) 매달 빠져나가는 정기결제·구독 목록 (안 쓰는 것 같은 건 표시)
  3) 다음 달 바로 줄일 수 있는 지출 3개와 예상 절약액
  ```
- 주의: 계좌번호·카드번호 전체는 절대 올리지 않는다.

## 6. 퇴근 10분 전 회의록 끝내기

- 표지: "회의록 담당 직장인에게 / 녹음 1개로 회의록 3분 컷" — 부제: 회의록은 막내 일이라고요? 잘 쓰는 사람이 승진합니다
- 순서
  1. 회의 녹음(참석자 동의) → 폰 녹음앱의 텍스트 변환 또는 AI에 파일 업로드.
  2. 변환된 텍스트를 붙여넣고 아래 프롬프트.
  3. 결정사항·담당자만 한 번 더 확인 후 공유.
- 복붙 프롬프트
  ```
  아래 회의 내용을 회의록으로 정리해줘.
  형식: 회의 목적 1줄 / 결정된 것 / 할 일(담당자, 마감일) 표 / 다음 회의 안건.
  누가 무슨 말을 했는지 확실하지 않은 부분은 [확인 필요]로 표시해.
  ---
  (텍스트 붙여넣기)
  ```
- 주의: 회사 기밀·고객 정보는 회사가 허용한 AI 도구에서만.

## 7. 엑셀 함수 몰라도 말로 시키기

- 표지: "엑셀 쓰는 직장인에게 / 함수 몰라도 되는 질문법 3가지" — 부제: 아직도 VLOOKUP 검색하고 있죠?
- 순서
  1. 표 맨 위 2~3줄을 캡처(열 이름이 보이게).
  2. 하고 싶은 걸 말로 쓴다.
  3. 나온 수식을 그대로 셀에 붙여넣는다.
- 복붙 프롬프트
  ```
  첨부한 엑셀 표에서 A열은 이름, B열은 부서, C열은 매출이야.
  (하고 싶은 것: 부서별 매출 합계를 다른 시트에 자동으로 정리)
  붙여넣기만 하면 되는 수식과, 어느 셀에 넣어야 하는지 알려줘.
  수식이 틀렸을 때 확인할 점도 1줄로.
  ```

## 8. 중고거래 판매글 10초

- 표지: "당근 하는 사람에게 / 사진 3장으로 판매글 10초" — 부제: 설명 대충 쓰면 네고만 들어옵니다
- 복붙 프롬프트
  ```
  첨부한 사진의 물건을 중고로 팔려고 해. 구매 시기: ( ), 사용감: ( ), 희망가: ( ).
  당근마켓 판매글로 써줘. 제목 20자 이내, 본문에 상태·구성품·거래방법,
  사진에서 보이는 흠집은 솔직하게 먼저 적어줘. 비슷한 물건 시세 범위도 추정해줘.
  ```
- 주의: 시세는 AI 추정. 실제 판매완료 가격을 앱에서 한 번 검색.

## 9. 챗GPT에 절대 넣으면 안 되는 정보

- 표지: "챗GPT 매일 쓰는 사람에게 / 절대 입력 금지 정보 5가지" — 부제: 주민번호 넣어본 적 있죠?
- 5가지: 주민등록번호·여권번호 / 카드·계좌 비밀번호와 전체 번호 / 회사 기밀·고객 개인정보 / 타인의 얼굴·실명이 담긴 사진 / 아이디·비밀번호·인증코드
- 행동 카드: 설정에서 대화 기록·학습 사용 여부 확인, 민감한 대화는 임시 채팅 또는 잠금 기능.

## 10. AI 거짓말 걸러내는 질문 1개

- 표지: "AI 답을 그대로 믿는 사람에게 / 거짓말 걸러내는 질문 1개" — 부제: AI는 모르면 지어냅니다
- 복붙 프롬프트
  ```
  방금 답변에서 확실한 사실과 추측을 나눠서 표로 보여줘.
  사실에는 내가 직접 확인할 수 있는 출처(기관명·문서명)를 붙이고,
  모르는 건 모른다고 써줘.
  ```

## 운영 메모

- 위 10개 × (표지 1 + 따라 하기 2~3 + 프롬프트 1 + 주의/행동 1) = 하루 2개씩 5일치.
- 같은 주제를 타겟만 바꿔 재활용: 예) 3번을 "부모님께" → "할머니 할아버지께", 7번을 "직장인" → "대학생 과제".
- 반응 좋은 주제는 다음 주에 "2편: 이것도 됩니다"로 이어간다.
