# 인스타그램 AI 카드뉴스 수익화 플레이북

출처: 『하루 30분, 인스타그램 AI 카드뉴스 수익화』 (노마드마진, 2026-08) 요약.
아래 수치·정책은 저자 주장이며 직접 검증되지 않았다. 시작 전 인스타 프로페셔널 대시보드의 수익화 메뉴에서 실제 조건을 확인할 것.

## 1. 전제

- 인스타 캐러셀(카드뉴스) 조회수 수익화가 2025년 12월 한국에 오픈 (미국·일본·한국 3개국).
- 대부분 릴스에 몰려 있어 카드뉴스는 아직 초기 시장.
- 네이버 카드뉴스(블로그 이미지 장식, 수익 없음)와 이름만 같고 완전히 다른 시장.

## 2. 수익 구조

자격 / 세팅 순서:
1. 프로페셔널 계정으로 전환
2. 수익화 자격 충족: 팔로워 1,000명 + 월 조회수 100만을 3개월 유지
3. 정산 계좌 등록
4. 카드뉴스 업로드 → 조회수에 따라 자동 적립

운영 규칙:
- 하루 수익 인정은 **5개까지**. 6개째부터는 조회수가 나와도 수익 없음.
- 실전: 하루 6~10개 업로드 → 1~2일 뒤 반응 약한 것 삭제 → 잘 된 5개만 남김.
- 정산 **2주 단위** (저자 사례: 2주에 US$241.80 / US$310.37).
- 부수입: 광고 문의(건당 100~200만 원), 전자책·굿즈, 쇼핑태그, 릴스 병행.

## 3. 알고리즘 논리

- 카드뉴스는 **저장 + DM 공유**로 확산. DM 공유 가중치는 좋아요의 3~5배.
- 저장이 쌓이면 탐색탭 노출 → 팔로워가 아닌 사람에게 확산. 팔로워 0이어도 가능.
- 재노출: 릴스 1회, 카드뉴스 2~3회.
- "팔로워가 콘텐츠를 퍼뜨리는 게 아니라 콘텐츠가 팔로워를 데려온다."

## 4. 도구

| 도구 | 용도 |
|---|---|
| GPT (ChatGPT) | 글감(카피) 생성 |
| Claude Design | 카드뉴스 기본 틀 생성 (HTML/CSS 기반, 한글 깨짐 없음, 부분 수정 가능) |
| 캔바 또는 피그마 | 틀에 글감 넣어 반복 생산 (AI 연결 가능) |

- 미리캔버스는 한글 폰트는 좋지만 AI 연결이 안 돼 대량 생산에 불리.
- 1장 제작 시간(저자 실측): 포토샵 40분 / Figma 30분 / 캔바 15분 / Claude Design 5분.
- Claude Pro 이상 권장 (무료는 사용량 제한으로 작업이 끊김).
- Claude Design 접속: 클로드 웹/앱 → 왼쪽 메뉴 [Design].

## 5. 규격

| 용도 | 사이즈 |
|---|---|
| 인스타 피드 세로 (기본) | **1080 × 1350 (4:5)** |
| 인스타 피드 정사각형 | 1080 × 1080 |
| 스토리 / 릴스 | 1080 × 1920 |
| 스레드 이미지 | 1080 × 1350 |

- 세이프 존: 상하좌우 **120px** 비우기, 핵심 카피는 중앙 80% 안쪽.
- 프롬프트에 사이즈를 반드시 명시 (안 쓰면 1080×1080으로 나옴).

## 6. 프롬프트 작성법

3칸만 채운다:

| 칸 | 넣을 것 | 예시 |
|---|---|---|
| ① 무엇을 | 매체 + 크기 + 형태 | 인스타 1080×1350 카드뉴스 1장 |
| ② 누구에게 | 타깃 + 공감 포인트 | 30대 직장인, 퇴근 후 시간이 없는 |
| ③ 어떤 느낌으로 | 톤 + 색 + 레이아웃 | 미니멀 모던, 어두운 배경, 여백 넉넉 |

감정어 대신 수치·키워드로:

| 이렇게 말하지 마세요 | 이렇게 말하세요 |
|---|---|
| 예쁘게 해줘 | 미니멀 / 모던 / 팝 중 하나 지정 |
| 글자 크게 | 제목 72px, 본문 32px |
| 색 자유롭게 | HEX 코드 2~3개 지정 |
| 여백 많이 | 상하좌우 120px 패딩 |
| 임팩트 있게 | 제목 배경에 강조색 블록 |
| 눈에 띄게 | 굵기 Black + 크기 72px 이상 |
| 센스 있게 | 레퍼런스 이미지 첨부 |

- 카드에 들어갈 텍스트는 반드시 **따옴표("")** 로 감싸기 (안 감싸면 지시사항으로 오해).

### 템플릿

```
인스타 1080×1350 카드뉴스 1장 만들어줘.
타깃: ______ 톤: ______
메인 컬러: #______ / 포인트 컬러: #______ 폰트: 한글 Pretendard, 영문 Inter
제목: "" 본문: "" 하단: @내핸들
※ 상하좌우 120px 안전 여백 확보 ※ 제목은 중앙 상단, 본문은 중앙 정렬
※ 렌더링 결과를 브라우저에서 바로 볼 수 있게 HTML로 만들어줘.
```

### 실습 예시

```
인스타 1080×1350 카드뉴스 1장 만들어줘.
타깃: 30대 직장인 여성 톤: 미니멀 모던, 정보 밀도 중간

제목: "퇴근 후 30분 루틴" 본문: "하루를 리셋하는 3가지 행동" 하단: @mybrand_official
※ 상하좌우 120px 안전 여백 확보 ※ 제목은 중앙 상단, 본문은 중앙 정렬
※ 렌더링 결과를 브라우저에서 바로 볼 수 있게 HTML로 만들어줘.
```

### 수정·저장

- 말로 수정: "제목 폰트 조금만 키워줘", "배경색 좀 더 밝게", "포인트 컬러를 보라색으로".
- 저장: 결과물 우클릭 → 이미지 복사, 또는 "이 카드뉴스 하단에 'PNG 다운로드' 버튼을 추가해줘."
- 여러 장: "전체 ZIP 다운로드 버튼도 추가해줘."
- 틀 확장: "배경화면 이미지 넣는 칸도 만들어줘", "카드 상단에 이미지 넣는 자리도 추가해줘."

## 6-1. 후킹 원칙 (벤치마킹: 조회 160만 vs 1.1만 비교)

같은 계정의 두 게시물 비교. 160만은 "2026년 군대가는 후임에게 / 25살 선임이 전하는 말", 1.1만은 "모두가 너처럼 살 수는 없어 라는 말을 듣는 사람이 되자".
**가장 중요도가 높은 세 가지: 숫자, 정확한 타겟, 반박하고 싶은 부제목.**

표지(썸네일):
- **숫자**로 직관적인 제목 (2026년, 25살, 3가지)
- **"~이 ~에게"** 형태로 누가 누구에게 하는 말인지 정확한 타겟
- **반박하고 싶은 부제목**: 읽는 사람이 "아닌데?" 하고 반응하게 만드는 단정적 문장

망하는 표지:
- 추상적인 제목 ("모두가 너처럼…라는 말을~")
- 다음 장이 딱히 궁금하지 않음
- 타겟이 존재하지 않음

본문 카드:
- 한 문장이 길지 않게
- 정확한 권위 제시 ("나는 ~한 사람이다")
- 공유하고 싶은 글
- 마지막엔 정확한 행동 지시 ("이걸 해라")
- 내용에 알맞는 사진

예시 변환:
- 나쁨: "퇴근 후 30분 루틴" / "하루를 리셋하는 3가지 행동"
- 좋음: "30대 직장인에게 퇴근 후 30분 루틴" / "주말에 몰아 쉬는 사람은 평생 피곤합니다"

## 6-2. 후킹 원칙 2: 채널 방향과 맞물리는 썸네일 (벤치마킹: 포엠매거진 @poemmag, 팔로워 8.1만)

시집 추천 계정인데 시집에 관심 없는 사람까지 팔로우하게 만든 사례.
- **시 구절을 그대로 썸네일 제목으로 쓴다.** 예: "멀어진다 / 사랑받았던 속도로 / 그만큼의 힘으로", "그러니까 나는, / 다음이라는 말과 연애하였지", "그때 우리는 / 헤어지는 것에 / 그토록 집중했기에"
- 제목 = 채널이 다루는 콘텐츠 그 자체. 따로 지어낸 카피가 아니라 원문 한 구절이라 채널 방향과 완벽하게 맞물린다. 시인이 카피라이터를 대신해 주는 셈.
- 형식: 분위기 있는 사진을 풀블리드로 깔고, 하단 왼쪽에 2~3줄 글귀, 하단 중앙에 작은 채널명.
- 문장이 끝나지 않고 걸려 있다 ("~했기에", "~나는,") → 다음 장이 궁금해진다.

6-1과의 관계:
- 정보형 채널(조언·뉴스·노하우)은 6-1 (숫자 + 타겟 + 반박 부제목).
- 감성형 채널(시·글귀·연애·위로)은 6-2 (원문 한 구절 + 사진 + 미완결 문장).
- 공통: 썸네일만 봐도 이 채널이 뭘 하는 곳인지 보이고, 다음 장을 넘기게 만든다.

카드뉴스 공방의 "사진 글귀" 카드 종류가 이 형식이다.

## 7. 매일 루틴

1. 주제 고르기 (통로 2개)
   - **벤치마킹 계정에서 터진 글**: 평소 대비 반응·저장이 몇 배 나온 글. 주제·구조만 가져오고 문장은 베끼지 않는다.
   - **내 분야 뉴스**: 사실만 가져와 내 말로 정리 + "이 뉴스가 나한테 무슨 의미인지" 한 줄.
2. 틀을 열고 주제 입력 → "카피 생성하기"
3. 나온 글을 내 말로 다듬기
4. PNG 저장 → 인스타 업로드

- 처음엔 1장짜리로 시작, 매일 최소 5개 올리는 습관이 목표. 이후 2~3장, 다계정으로 확장.
- 핵심: "AI를 잘 쓰는 비결은 AI한테 뭘 시킬지 고르는 눈."
