## 1. 전제

- 인스타 캐러셀(카드뉴스) 조회수 수익화가 2025년 12월 한국에 오픈 (미국·일본·한국 3개국).
- 대부분 릴스에 몰려 있어 카드뉴스는 아직 초기 시장.
- 네이버 카드뉴스(블로그 이미지 장식, 수익 없음)와 이름만 같고 완전히 다른 시장.

## 2. 수익 구조

자격 / 세팅 순서:
1. 프로페셔널 계정으로 전환
2. 수익화 자격 충족: 팔로워 1,000명 + 월 조회수 100만을 3개월 유지
3. 정산 계좌 등록
4. 카드뉴스 업로드 → 조회수에 따라 자동 적립

운영 규칙:
- 하루 수익 인정은 **5개까지**. 6개째부터는 조회수가 나와도 수익 없음.
- 실전: 하루 6~10개 업로드 → 1~2일 뒤 반응 약한 것 삭제 → 잘 된 5개만 남김.
- 정산 **2주 단위** (저자 사례: 2주에 US$241.80 / US$310.37).
- 부수입: 광고 문의(건당 100~200만 원), 전자책·굿즈, 쇼핑태그, 릴스 병행.

## 3. 알고리즘 논리

- 카드뉴스는 **저장 + DM 공유**로 확산. DM 공유 가중치는 좋아요의 3~5배.
- 저장이 쌓이면 탐색탭 노출 → 팔로워가 아닌 사람에게 확산. 팔로워 0이어도 가능.
- 재노출: 릴스 1회, 카드뉴스 2~3회.
- "팔로워가 콘텐츠를 퍼뜨리는 게 아니라 콘텐츠가 팔로워를 데려온다."

## 6-1. 후킹 원칙 (벤치마킹: 조회 160만 vs 1.1만 비교)

같은 계정의 두 게시물 비교. 160만은 "2026년 군대가는 후임에게 / 25살 선임이 전하는 말", 1.1만은 "모두가 너처럼 살 수는 없어 라는 말을 듣는 사람이 되자".
**가장 중요도가 높은 세 가지: 숫자, 정확한 타겟, 반박하고 싶은 부제목.**

표지(썸네일):
- **숫자**로 직관적인 제목 (2026년, 25살, 3가지)
- **"~이 ~에게"** 형태로 누가 누구에게 하는 말인지 정확한 타겟
- **반박하고 싶은 부제목**: 읽는 사람이 "아닌데?" 하고 반응하게 만드는 단정적 문장

망하는 표지:
- 추상적인 제목 ("모두가 너처럼…라는 말을~")
- 다음 장이 딱히 궁금하지 않음
- 타겟이 존재하지 않음

본문 카드:
- 한 문장이 길지 않게
- 정확한 권위 제시 ("나는 ~한 사람이다")
- 공유하고 싶은 글
- 마지막엔 정확한 행동 지시 ("이걸 해라")
- 내용에 알맞는 사진

예시 변환:
- 나쁨: "퇴근 후 30분 루틴" / "하루를 리셋하는 3가지 행동"
- 좋음: "30대 직장인에게 퇴근 후 30분 루틴" / "주말에 몰아 쉬는 사람은 평생 피곤합니다"

## 6-2. 후킹 원칙 2: 채널 방향과 맞물리는 썸네일 (벤치마킹: 포엠매거진 @poemmag, 팔로워 8.1만)

시집 추천 계정인데 시집에 관심 없는 사람까지 팔로우하게 만든 사례.
- **시 구절을 그대로 썸네일 제목으로 쓴다.** 예: "멀어진다 / 사랑받았던 속도로 / 그만큼의 힘으로", "그러니까 나는, / 다음이라는 말과 연애하였지", "그때 우리는 / 헤어지는 것에 / 그토록 집중했기에"
- 제목 = 채널이 다루는 콘텐츠 그 자체. 따로 지어낸 카피가 아니라 원문 한 구절이라 채널 방향과 완벽하게 맞물린다. 시인이 카피라이터를 대신해 주는 셈.
- 형식: 분위기 있는 사진을 풀블리드로 깔고, 하단 왼쪽에 2~3줄 글귀, 하단 중앙에 작은 채널명.
- 문장이 끝나지 않고 걸려 있다 ("~했기에", "~나는,") → 다음 장이 궁금해진다.

6-1과의 관계:
- 정보형 채널(조언·뉴스·노하우)은 6-1 (숫자 + 타겟 + 반박 부제목).
- 감성형 채널(시·글귀·연애·위로)은 6-2 (원문 한 구절 + 사진 + 미완결 문장).
- 공통: 썸네일만 봐도 이 채널이 뭘 하는 곳인지 보이고, 다음 장을 넘기게 만든다.

카드뉴스 공방의 "사진 글귀" 카드 종류가 이 형식이다.

### 공통 법칙
1. **피드 전체가 한 템플릿.** 위치·태그·폰트가 매번 같아서 그리드만 봐도 계정이 보인다.

3. **돈과 숫자가 1순위 후킹.** 무료/공짜/월 얼마/몇 개/몇 %.
4. **말투는 반말 섞인 구어체.** "~하세요", "ㄴㄴ", "~인 거 아세요?"
5. **이미지가 증거 역할.** oaiwan은 실제 UI·가격 화면을 보여줘서 "진짜다"가 한눈에 보인다.

## 7. 애드맨 고정 룰 (2026-10-27 추가)

- **훅 = "누구처럼 되기".** 평범한 목표를 다들 아는 사람·캐릭터로 바꿔 말한다. 숫자도 같이 넣는다.
  - 다리근육 키우기 → 한마 바키 다리 만들기
  - 피부 좋아지기 → 손예진 피부 되기
  - 롤 잘하기 → 페이커 되는 법
  - 그림 잘 그리기 → 피카소처럼 그리기
  - 돈 모으기 → 워런 버핏처럼 돈 모으기 (#003)
- **주제는 항상 먼저 물어본다.** 내가 임의로 골라서 만들지 않는다. 후보를 보여주고 고르면 제작.
- **마지막 장 = 댓글 참여 유도.** "댓글에 '키워드' 남기면 프롬프트 원문 DM". 이미지 속 프롬프트는 복사가 안 되니 원문을 DM으로 주는 게 명분. 캡션에도 같은 키워드.
