수집일: 2026-11-07 (바이럴 기준으로 재선별)
출처: 인스타 릴스 피드(@algorithmismylife 계정으로 로그인된 피드)를 120개 내려가며 수집 → AI·클로드 관련 해외 릴스 47개 추림(전체는 CSV) → 상위 18개는 영상 프레임 확인 + 캡션 전문 + 깃허브 저장소 실재/별/라이선스 확인.

## 1. 해외에서 터지는 공식

짐코딩 공식(손해 선고 훅 → 이름 공개 → 비유 → 주의점 → 댓글 키워드 DM)은 해외에서도 그대로 통함. 해외에서 추가로 보이는 것:

- **댓글 키워드가 소재마다 다름** ("HARVEY", "LIMIT", "REPO", "YOUTUBE", "3D"). 짐코딩은 "클로드" 고정. 둘 다 됨. 소재별 키워드는 어떤 소재가 DM을 많이 받았는지 측정하기 좋음.
- **"Follow so the DM lands 📩"**: 팔로우 안 하면 DM이 요청함으로 빠진다는 이유로 팔로우를 자연스럽게 요구. 한국판: "팔로우해야 DM이 바로 도착해요".
- **캡션에 "👇 READ BELOW" + 번호 목록 + "The catch:"(함정) 섹션**. 단점·조건을 먼저 밝혀 신뢰를 삼. 짐코딩의 "주의" 섹션과 같은 역할.
- **영상 길이가 훨씬 짧음**: 상위 해외 정보형은 23~68초(짐코딩 80초). 대신 캡션에 정보를 몰아넣음.
- **시각 포맷이 다양함** (전부 얼굴 없이도 됨):
  - 클로드 오렌지 마스코트 일러스트 + 큰 숫자 (chenbuildsai: Opus 동전이 쪼개지며 limit 100%→39%)
  - 3D 블록 캐릭터 무대 + 상단 테이프 제목 (nocodealex)
  - 앱 로고 카드 그리드에 "PAID" 도장 → "FREE"로 바뀜 (ai.nxtlvl)
  - 픽셀 게임 화면 (jayantcreates: "ROUND 1", "FINAL ROUND", "CONTINUE?")
  - 지하철 노선도식 시스템 다이어그램 (restructureai: 23명 AI 직원)
  - 얼굴 + 상단 화면 분할 (nick_saraev, nocode.joshua, aiwithremy)
- **시리즈화**: "Skill of the Week", "Ep 5 of 7", "explain it like I'm five, part 1", 캐릭터 연재(Ash & Claude). 팔로우 이유를 만들어 줌.

### 2-3. 바이럴에서 공통으로 보이는 것
- **평소 대비 수십~수백 배 터진 건 대부분 팔로워 1만 이하 작은 계정**(ene.wya 4,924명, motionloved 3,948명, restructureai 3,295명). 계정 크기보다 소재·포맷이 결정함 → 신규 계정도 가능.
- 터진 것의 절반이 **결과물을 먼저 보여주는 영상**(쇼핑몰 사이트, 모션그래픽, 분해도, 도면, 3D 캐릭터). 설명만 하는 영상은 댓글 유도가 강해야 터짐.
- 댓글율 3% 넘는 건 전부 **"내가 만든/찾은 걸 통째로 줌"**(스킬, 프롬프트, 저장소 링크) + 소재별 키워드.
- 리포스트 많은 건 밈·콩트(themarketinginterns 13,272, canwebuildthis 3,271). 정보형은 공유는 높아도 리포스트는 낮음.

## 3. 바로 쓰는 한국판 대본 3편

공통: 짐코딩 9단계 공식, 해요체, 자막 한 줄 18자 이하, 약 60~75초. (계정명)/(키워드)는 바꿔 쓰기. 화면 지시는 검정 배경 + 오렌지 포인트 기준.

### 대본 1. "AI 대본이 뻔한 이유" (원본 @aiwithremy, 댓글율 7.47%)

원본 요지(자막 복원): AI에게 바이럴 훅을 아무리 먹여도 글이 별로인 건, AI가 "1단계 강한 주장 → 2단계 번호 목록 → 3단계 CTA" 같은 단계만 베끼고 그 뒤의 생각은 놓치기 때문. 해결은 단계 대신 원칙(호기심 루프, 구체성, 첫 줄이 다음 줄을 팔게 하기)을 가르치는 스킬.
한국판은 내가 만든 원칙 프롬프트(짐코딩 분석 마스터 프롬프트를 다듬은 것)를 리드마그넷으로. **원본의 성과 수치(조회 2배, 팔로워 1.5만)는 그 사람 것이라 쓰면 안 됨. 내 실험 결과가 생기면 그 숫자로 바꿀 것.**

## 4. 클로드에 넣는 "해외 레퍼런스 현지화" 프롬프트

지난번 마스터 프롬프트를 먼저 붙여 넣은 다음, 이걸 이어서 붙여 넣고 해외 릴스 캡션(또는 자막)을 주면 됨.

```
지금부터 해외 릴스를 레퍼런스로 한국판을 만든다. 규칙:

1. 번역하지 말고 현지화한다. 원본 문장, 원본 영상 구성, 원본 캐릭터·디자인은 쓰지 않는다. 가져오는 건 "소재(도구/방법)"와 "왜 터졌는지"뿐이다.
2. 원본 주장은 전부 의심한다. 저장소 이름·별 수·라이선스·설치 명령·가격·배수(예: 70배 절감)는 공식 저장소 README나 공식 문서에서 다시 확인하고, 확인 못 한 주장은 대본에서 빼거나 "확인 필요"로 표시한다. 이름이 바뀌었거나 라이선스가 달라졌으면 최신 기준으로 쓴다.
3. 원본이 DM으로만 배포하는 비공개 스킬이면, 같은 효과를 공개 도구나 공식 기능으로 직접 구현하는 각도로 바꾼다.
4. 한국 시청자 기준으로 바꾼다: 해외 서비스는 한국에서 많이 쓰는 서비스로 비교(예: 캘린들리보다 노션·일레븐랩스·카톡·네이버), 한국 법·문화상 위험한 부분(광고성 메일, 링크드인/인스타 자동화, 음성 복제 동의, 상표)은 주의점으로 만든다.
```
