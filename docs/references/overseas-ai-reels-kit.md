## 1. 해외에서 터지는 공식

짐코딩 공식(손해 선고 훅 → 이름 공개 → 비유 → 주의점 → 댓글 키워드 DM)은 해외에서도 그대로 통함. 해외에서 추가로 보이는 것:

- **댓글 키워드가 소재마다 다름** ("HARVEY", "LIMIT", "REPO", "YOUTUBE", "3D"). 짐코딩은 "클로드" 고정. 둘 다 됨. 소재별 키워드는 어떤 소재가 DM을 많이 받았는지 측정하기 좋음.
- **"Follow so the DM lands 📩"**: 팔로우 안 하면 DM이 요청함으로 빠진다는 이유로 팔로우를 자연스럽게 요구. 한국판: "팔로우해야 DM이 바로 도착해요".
- **캡션에 "👇 READ BELOW" + 번호 목록 + "The catch:"(함정) 섹션**. 단점·조건을 먼저 밝혀 신뢰를 삼. 짐코딩의 "주의" 섹션과 같은 역할.
- **영상 길이가 훨씬 짧음**: 상위 해외 정보형은 23~68초(짐코딩 80초). 대신 캡션에 정보를 몰아넣음.
- **시각 포맷이 다양함** (전부 얼굴 없이도 됨):
  - 클로드 오렌지 마스코트 일러스트 + 큰 숫자 (chenbuildsai: Opus 동전이 쪼개지며 limit 100%→39%)
  - 3D 블록 캐릭터 무대 + 상단 테이프 제목 (nocodealex)
  - 앱 로고 카드 그리드에 "PAID" 도장 → "FREE"로 바뀜 (ai.nxtlvl)
  - 픽셀 게임 화면 (jayantcreates: "ROUND 1", "FINAL ROUND", "CONTINUE?")
  - 지하철 노선도식 시스템 다이어그램 (restructureai: 23명 AI 직원)
  - 얼굴 + 상단 화면 분할 (nick_saraev, nocode.joshua, aiwithremy)
- **시리즈화**: "Skill of the Week", "Ep 5 of 7", "explain it like I'm five, part 1", 캐릭터 연재(Ash & Claude). 팔로우 이유를 만들어 줌.
