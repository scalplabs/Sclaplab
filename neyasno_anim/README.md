# 네야스노 분위기 2D 픽셀 애니 — EP01 「나라는 멀쩡한데 나는 붕괴했다」

`neyasno_style_guide.md`와 레퍼런스 캡처 10장을 보고 분위기와 구조만 가져와서 오리지널로 만든 3분 48초짜리 애니.
게임 에셋, 원문 대사, 채널 브랜딩은 쓰지 않았다.

| 경로 | 내용 |

## 인스타 릴스 1분판 `insta01.mp4` 「확실한 건 없다」
- 1080x1920 세로. 픽셀 화면(960x540)을 가운데 두고 자막은 아래 검은 여백에 넣어서 인스타 UI에 안 가린다.
- 4개 장면을 대략 15초씩: 동네 독백 → 편의점 아저씨 → 옥상 → 택시에서 잠듦. 대사 사이에 1~2초씩 쉰다.
- 대사는 허무주의 쪽으로 새로 썼다 (`script/insta01.txt`).
- 배경음은 처음부터 끝까지 이어지는 음침한 스코어: 저음 드론, Em-C-Am-B 패드, 드문드문 떨어지는 피아노 음, 심장 박동 같은 저음, 긴 울림. 그 아래에 빗소리, 택시에서는 엔진 소리.
- 렌더: `python3 render.py --episode insta01` (약 1분)

## 다시 렌더하기
```bash
pip install numpy pillow scipy   # ffmpeg도 필요
python3 render.py                # ep01.mp4 생성 (4코어 기준 약 3~4분)
python3 render.py --still 77     # 77초 프레임 하나만 PNG로 확인
```
대사를 바꾸려면 `script/ep01.txt`만 고치고 다시 렌더하면 된다. 목소리도 대본에서 자동으로 다시 만들어진다.
`python3 render.py --audio-only --out test.wav`로 사운드만 빠르게 뽑아 들어볼 수 있다.

## 기계음 목소리 (외부 API 없음)
대사의 한글을 음절(초성, 중성, 종성)로 쪼개서 직접 합성한다.
- 모음마다 실제 모음의 포먼트(F1, F2, F3)를 톱니파 성대음에 걸어서 "말하는 것 같은데 알아듣긴 힘든" 소리를 낸다. 이중모음은 앞뒤 반으로 나눠서 미끄러진다.
- 초성 ㄱㄷㅂ류는 짧은 파열 노이즈, ㅅㅈㅊ류는 쉬익 소리, ㅎ는 숨소리, ㄴㅁ는 웅 소리. 종성 ㄴㅁㅇ는 끝을 끈다.
- 음높이는 반음 단위로 끊어서 기계 느낌을 낸다. 샘플레이트와 비트를 깎아서 레트로 게임 소리로 만든다.
- **해설(A)**: 205Hz, 음절당 약 0.085초, 물음표면 끝을 올림. **강조(A!)**는 조금 낮고 느리고 크게.
- **극중 대사(B)**: 92Hz, 음절당 약 0.15초, 문장 끝으로 처짐. 링모듈레이션과 울림을 넣어 지친 NPC 느낌.
- 대사가 나오는 동안 배경음을 0.6초에 걸쳐 부드럽게 절반으로 줄인다.
- 톤은 `render.py`의 `VOICES` 표에서 바꾼다.
