# 네야스노 분위기 2D 픽셀 애니 — EP01 「나라는 멀쩡한데 나는 붕괴했다」

`neyasno_style_guide.md`와 레퍼런스 캡처 10장을 보고 분위기와 구조만 가져와서 오리지널로 만든 3분 48초짜리 애니.
게임 에셋, 원문 대사, 채널 브랜딩은 쓰지 않았다.

## 파일
| 경로 | 내용 |
|---|---|
| `ep01.mp4` | 완성 영상 (1280x720, 24fps, 합성 사운드 포함, 자막 번인) |
| `script/ep01.txt` | 대본. `[시작-끝] [층] 대사 \| 영어` 형식. 렌더러가 이 파일을 읽어서 자막을 얹는다 |
| `render.py` | 장면, 사운드, 자막을 전부 코드로 만드는 렌더러 |
| `fonts/` | 나눔고딕 ExtraBold (OFL) |

## 다시 렌더하기
```bash
pip install numpy pillow scipy   # ffmpeg도 필요
python3 render.py                # ep01.mp4 생성 (4코어 기준 약 3~4분)
python3 render.py --still 77     # 77초 프레임 하나만 PNG로 확인
```
대사를 바꾸려면 `script/ep01.txt`만 고치고 다시 렌더하면 된다. 해설(A) 목소리는 본인 녹음이나 직접 만든 TTS를 위에 얹는 걸 전제로, 지금은 자막과 앰비언스만 들어 있다.
