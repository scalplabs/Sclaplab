# 옮긴 방식과 원본과 달라진 점

원본: `reference/막차47_영상엔진.html` (캔버스 `renderAt(초)`), 비교 기준: `reference/막차47_PART1_원본.mp4`

## 부분별 방식

| 부분 | 방식 | Studio 에서 바꿀 수 있는 것 |
|---|---|---|
| 장면 그림 10개 (배경, 졸라맨, 휴대폰, 스피커, 문, 손, 선택지, 엔딩) | Hosted: 그림 코드 그대로, 시간만 HyperFrames 가 준다 | 장면 순서/길이, `<canvas data-...>` 의 글자(문자 내용, 말풍선, 선택지 A/B, 엔딩 문구, PART 번호) |
| 자막 28개 | Native: HTML + GSAP 팝 | 글자, 강조 단어, 시작 시간, 길이, 위치 |
| 좌상단 HUD | Native: HTML | 숫자, 글자, 보이는 구간 |
| 4번 숫자판(100, 상금 카운트업), 5번 숫자판(100 → 99, 역 이름, 탈락 표시) | Native: HTML + GSAP | 숫자, 글자, 카운트업 시작/끝 값과 시간 |

## 달라진 점

- 폰트: 원본은 맥의 Apple SD Gothic Neo / Menlo 를 가정했지만 렌더 환경에 없어서
  Noto Sans KR / JetBrains Mono 를 `assets/fonts/` 에 넣어 사용. 숫자 "1" 모양, 모노스페이스 글자 폭이 조금 다르다.
- 필름 그레인(프레임마다 흰 점 60개)은 캔버스에 남아 있어 자막/HUD 글자 "아래"에 깔린다(원본은 글자 위).
- 엔딩 카드의 하트(♥)와 플러스(+)는 폰트 글리프 대신 도형으로 그렸다.
- 장면/자막 시간은 소수 둘째 자리로 반올림했다. 프레임 경계에서 1프레임 차이가 날 수 있다.
- 오디오 없음(원본도 무음, narration.mp3 없음).
