## 2. Claude Code로 영상 만들기: 조사 결과

**결론: 된다.** 표준 방법은 **Remotion**(React 코드 → MP4 렌더링 프레임워크)이다.

- Remotion 공식 문서에 Claude Code 같은 코딩 에이전트로 영상을 만드는 가이드가 있다.
- Remotion이 Claude Code용 **공식 Agent Skills**를 제공한다(`/remotion-best-practices`, `/remotion-create`, `/remotion-render` 등).
- Flashloop 등 AI 영상 툴은 MCP로 Claude에 연결해서 AI 이미지/영상 컷을 받아올 수도 있다(유료 크레딧).

### 내 맥에서 세팅 (터미널)
```bash
# 1) Node.js 설치되어 있어야 함
npx create-video@latest --yes --blank makcha47
cd makcha47
npx remotion skills add      # Claude Code용 Remotion 스킬 설치
npm run dev                  # 미리보기 스튜디오 (브라우저)
# 2) 다른 터미널에서
cd makcha47 && claude
```

### Claude Code에 붙여넣을 프롬프트 (예시)
```
/remotion-create
1080x1920, 30fps 세로 숏폼 "막차 47 PART 1"을 만들어줘.
스타일: 어두운 네이비 배경 플랫 2D, 베이지색 둥근 졸라맨(검은 외곽선, 가슴에 번호표), SVG로 그려.
화면 좌상단 HUD: "남은 인원 N명" 큰 숫자 + 아래 작은 "상금 ₩"(모노스페이스), 장면마다 값이 바뀜.
자막: 화면 60% 높이, 1~3단어씩, 900 굵기 흰 글씨 + 검은 외곽선, *별표* 친 단어는 노란색, 등장할 때 살짝 튀어나오게.
장면은 하드컷. 장면 목록과 자막 타이밍은 아래 표를 그대로 써.
public/narration.mp3 가 있으면 <Audio>로 깔고, 없으면 무음.
마지막 엔딩: "너라면 뭐 할래?" + 댓글 입력창 타이핑 연출 + "댓글 1등이 PART 2를 정한다" + 로고 카드.
[여기에 아래 3번 대본 표 붙여넣기]
```

### 이번 작업에서 실제로 한 것
- Aside 작업 환경은 보안상 외부 실행 파일(esbuild, ffmpeg, 헤드리스 크롬)과 macOS 음성 합성이 막혀 있어서 Remotion 렌더가 안 됨.
- 대신 Remotion과 같은 원리(코드로 프레임 그리기 → H.264 MP4 인코딩)로 브라우저에서 직접 렌더링함 → `막차47_PART1.mp4` (1080x1920, 44초, 무음)
- 엔진 소스: `막차47_영상엔진.html` (장면 목록 `S`, 자막 `chunks`만 고치면 Part 2 제작 가능)
